# 🌐 MR.SKY AI Browser

A fast, lightweight, tabbed desktop browser powered by Electron and Chromium, styled with a cyberpunk neon interface.

## ✨ Features

- **📑 Multi-Tab Management**: Create, switch, and close tabs dynamically.
- **🔍 Smart Address Bar**: Search Google directly or enter web URLs with automatic protocol detection.
- **⚡ Direct AI Hub**: Quick-access shortcuts to ChatGPT, Gemini, DeepSeek, and Claude from the homepage.
- **🕘 Browsing History**: Automatically tracks visited URLs with timestamps and deduplication.
- **🔄 Tab-aware Controls**: Full support for Back, Forward, Reload/Stop, and Home on whichever tab is currently active.
- **🎯 Link Handling**: External `target="_blank"` links open automatically in new tabs.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or newer recommended)
- npm

### Installation
```bash
git clone https://github.com/Sumit12312299/AI-Browser.git
cd AI-Browser
npm install
```

### Running the Browser
```bash
npm start
```

### Building the Installer (Windows)
```bash
npm run build
```
The installer will be generated in the `dist/` directory.
